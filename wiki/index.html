OCEANWORKS / WIKI

해역을 읽고,
흐름을 설계하세요.

탐사 결과를 해석하고 노드 기반 작업영역에서 해상 산업망을 구상하는 싱글플레이 전략 게임 프로젝트입니다.

현재는 인터페이스·시스템 프로토타입입니다.

완성된 캠페인이 아닙니다. 일부 자원·전력·임무 수치는 예시이며, 개별 화면의 시험 모델과 최종 통합 경제는 다릅니다.

FIRST SESSION

빠른 시작

  1. 창 추가에서 해역, 계획, 광물탐색기 등 필요한 창을 엽니다.
  2. 해역의 대상과 계획 화면을 살펴보고 좌표·노드 연결을 확인합니다.
  3. 계획에 스캔 노드를 추가하고 거점과 탐사 조건을 지정합니다.
  4. 계획에서 큐를 등록한 뒤 광물탐색기의 해당 큐에서 시작을 누릅니다.
  5. 탐사가 완료되면 결과보고로 자원·지질·환경 정보를 확인합니다.

테스트 완료 버튼이 있는 빌드에서는 기다리지 않고 보고서 동작을 확인할 수 있습니다. 실제 캠페인 규칙이 아닙니다.

WORKSPACE

창과 조작

내 작업영역

탭을 드래그해 창을 분리하고 다른 패널의 가장자리에 놓아 도킹합니다. 경계와 모서리로 크기를 조절합니다. 닫은 창은 창 추가에서 다시 엽니다.

배치 저장

작업영역 저장과 배치 복원으로 창 구성을 관리합니다. 작업영역 저장은 전체 게임 저장과 동일하지 않습니다.

계획·생산 편집

노드를 배치하고 연결해 구조를 표현합니다. 자동배치와 레이어·그룹을 활용해 도식을 정리할 수 있습니다.

관리자

색상 설정을 실험하는 개발용 창입니다. 돋보기로 화면 요소의 색상을 찾을 수 있습니다. 변경내용 보내기는 설정 공유를 돕는 기능이며 외부 AI에 자동 전송하지 않습니다.

MINERAL EXPLORER

광물탐색기

계획에서 탐사 조건을 설정하고, 광물탐색기에서 큐를 실행·중단하고 결과를 확인합니다. 큐의 거점명과 좌표를 확인해 어떤 스캐너인지 구분하세요.

요소읽는 방법
광범위 / 단거리광범위는 해역 전체, 단거리는 지정 범위 안을 대상으로 하는 시험 모델입니다.
진행과 중단진행에 따라 일부 정보가 공개됩니다. 중단 후 진행도를 유지하며 다시 시작할 수 있습니다.
원형 레이더반지름 방향은 수심이 아니라 자원 유형의 주파수 영역을 나타내는 가상 시각화입니다.
순도 히트맵20×10칸의 평균 밝기가 내부순도에 대응합니다. 호버로 내부순도를 확인합니다.
유형·가치·함량호버 또는 키보드 포커스로 1,000톤당 가치, 가치 계산식, 함량 범위 등을 확인합니다.
지질·환경암반, 수심, 해류, 파고, 풍속, 강수량, 조차, 깊이별 수온, 탄성파를 그래프로 표현합니다. 실제 관측 자료가 아닌 생성 데이터입니다.

현재 화면의 매장량·총가치 표현은 이전 모델입니다. 아래 설계 예정의 영구 광맥·광맥 규모 체계와 혼동하지 마세요.

RESOURCE DIRECTORY

다섯 유형, 스물두 자원

설계 분류 다음은 전체 자원 기획입니다. 현재 발견 가능한 종류와 최종 해금·확률은 이 목록 전체와 같지 않을 수 있습니다.

유형자원
구조재철 · 알루미늄 · 망간 · 티타늄 · 크롬 · 텅스텐
연료석유 · 천연가스 · 메탄하이드레이트
전도체구리 · 은 · 흑연 · 금
전지금속니켈 · 코발트 · 리튬 · 바나듐

내부순도는 게임 계산용 수치, 표시 함량은 자원별 계수로 변환한 표시값입니다. 서로 다른 자원의 함량 %만으로 효율을 비교하지 마세요.

OPERATIONS

생산 · 연구 · 교역

생산 관리

시설과 연결 관계를 노드로 구성하는 화면입니다. 생산·전력·물류를 모두 묶은 캠페인 경제는 개발 중입니다.

연구

연구 지도에서 항목과 선행 관계를 확인하고 연구 계획을 살펴봅니다. 캠페인의 기능 해금 순서는 확정 구현과 구분합니다.

교역

교역 화면의 개별 시험 모델을 제공합니다. 최종 가격·물량·외부 공급 제한은 조정 대상입니다.

계획

좌표와 작전·편성·탐사 노드를 연결합니다. 큐 등록과 실제 탐사 시작은 별도의 단계입니다.

DESIGN DIRECTION / NOT YET A COMPLETE GAME

설계 예정

아래는 목표로 하는 설계이며, 현재 빌드에서 전부 작동한다는 뜻이 아닙니다.

  • 3~5시간 싱글 캠페인. 챕터마다 기능과 판단을 단계적으로 학습합니다.
  • 광맥은 영구 유지하며, 광맥 규모가 추가 전력 투입 시 도달 가능한 최대 채굴량을 결정합니다.
  • 작은 광맥 여러 곳을 운영해 생산량을 확보할 수 있지만 운영 코어를 더 사용합니다.
  • 연산코어를 생산·탐사·전투에 배분하고 일시중단 시 상태를 보존합니다.
  • 범용 정제소에서 시작해 전문화하며 원광을 유형 자원으로 정제합니다.
  • 정기선은 연구로 해금하고 실제 운송량과 거리에 따라 연료를 사용합니다.
  • 탐사는 빈 프로파일 슬롯이 있어야 시작하며 진행 중에도 슬롯을 차지합니다.

SUPPORT

저장과 문제 해결

다른 기기에서 저장이 이어지나요?

현재는 브라우저의 로컬 저장소를 사용합니다. 계정·클라우드 저장은 없습니다. 다른 브라우저·기기·주소에서는 기존 저장이 자동으로 이어지지 않습니다.

로컬 테스트의 저장이 보이지 않아요.

localhost와 공개 사이트는 서로 다른 저장 영역입니다. 공개 사이트에서 새로 시작하는 것은 기존 로컬 데이터 삭제를 의미하지 않습니다.

화면이 좁거나 창이 가려져요.

PC의 넓은 화면을 권장합니다. 창을 이동·크기 조절하거나 작업영역 배치를 변경해 보세요. 모바일 플레이는 최적화되지 않았습니다.

버그는 어떻게 기록하나요?

화면 이름, 수행한 순서, 예상 결과, 실제 결과와 스크린샷을 남겨 주세요. 저장소 데이터에는 개인 메모가 포함될 수 있으니 전체 저장 데이터를 공개하지 마세요.

완성된 게임인가요?

아닙니다. 현재는 UI와 개별 기능을 시험하는 공개 프로토타입입니다. 성능·밸런스·경제 통합·캠페인은 개발 중입니다.
